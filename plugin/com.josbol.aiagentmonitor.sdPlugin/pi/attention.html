Plugin-wide settings
Reads the subscription windows from claude.ai / chatgpt.com / github.com with the tokens Claude Code, Codex and Copilot already store. Off = Codex usage from local logs only, no Claude usage. The Claude endpoint rate-limits eager clients for an hour at a time: keep the refresh at 5 min or slower (it is 3× slower anyway while no agent is working, and backs off by itself after a 429).

Approve / deny from the deck

How long a permission request waits for a deck press before the terminal shows its own dialog. Pressing the agent key / dial hands it to the terminal right away.
Skip the hold when the agent's window is already the active window (you are probably looking at it).
In ChatGPT-app sessions with automatic approval review, requests are not held: Codex's Guardian screens them first, and only what it rejects comes back to you — as a question in the app (the deck alerts). Uncheck to hold every request on the deck as usual.
Shows the full request on screen while it is held (the app's own prompt only appears after the hold). The dialog has Approve / Deny / "Decide in the app" buttons, a hold countdown, and never takes keyboard focus. The Qt window needs python3 with PyQt6, PySide6 or PyQt5.
Local port the Claude / Codex / Copilot hooks post to. After changing it: reload the plugin and run opendeck-aiagentmonitor --install-hooks again.
